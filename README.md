## Features

- Filters — Refine cards by age, gender, role, and other preferences.
- Browsing Presets — Switch between Default, Minimal, SFW, and your saved setups.
- Soft-Block And Block — Quiet unwanted profiles and access the site's block action.
- Media Visibility — Blur, hide, or show sensitive media.
- Seen Profiles — Recognize profiles you have already viewed.
- **Page helpers** — Visited nicknames, absolute times, shared interests, and convenient paging.
- Keyboard Shortcuts — Open the dock, navigate, and return to the top.
- Coordinated Launchers — Move installed edition badges together; Basic yields its badge when Pro is present.
- Local Settings — Save preferences on this device and reset them when needed.
